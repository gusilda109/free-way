# Свободный путь — MVP

Устанавливаемое веб-приложение (PWA) для пилотного района Новосибирска (Академгородок): карта препятствий,
пресет «Для коляски», предварительный маршрут по профилю wheelchair, добавление точки с фото
и сигнал «отметка изменилась». Сделано по ТЗ «Техническая архитектура и техническое задание
проекта Свободный путь».

## Быстрый старт

Нужен **Node.js 22.13 или новее** (используется встроенный SQLite, ставить базу данных не нужно).

```bash
npm install
cp .env.example .env      # на Windows: copy .env.example .env
npm run seed              # 9 демо-точек в Академгородке
npm run dev
```

Откройте http://localhost:5173. Запускаются два процесса: API на порту 8787 и клиент Vite
на 5173 (запросы `/api` проксируются на API).

С телефона в той же Wi-Fi сети: Vite печатает адрес `Network: http://192.168.x.x:5173`.
Установка PWA с телефона требует HTTPS, поэтому на локалке проверяется только интерфейс;
на компьютере установка работает с `localhost`.

## Где хранятся данные

Все в папке `data/` (путь меняется через `DATA_DIR`):

| Что | Где |
|---|---|
| Точки, сигналы, анонимные сессии, журнал запросов маршрута | `data/app.db` (SQLite) |
| Фотографии | `data/photos/<id сессии>/<id точки>.webp` |

Чтобы начать с чистого листа, остановите сервер и удалите `data/`.
Ручное удаление ошибочной точки (до появления админ-панели):

```bash
npm run delete-point -- <id точки>
```

ID точки виден в адресе фото (`/api/photos/<id>`) или в базе.

## Маршрут: движок OpenStreetMap, без ключа

По умолчанию маршрут строит **Valhalla** — открытый движок на данных OpenStreetMap, тот же,
что предлагается в разделе «Маршруты» на openstreetmap.org. Используется публичный сервер
FOSSGIS `valhalla1.openstreetmap.de` с пешеходным профилем `type: wheelchair`
(ниже скорость, ограничение уклона, ступени избегаются). Регистрация и ключ не нужны.

Публичный сервер FOSSGIS — демонстрационный: для разработки и пилота с малой нагрузкой
подходит, для постоянной работы стоит поднять свой Valhalla (Docker-образ
`ghcr.io/valhalla/valhalla-scripted` с выгрузкой Новосибирской области) и указать его
адрес в `VALHALLA_URL`.

Запасной вариант — OpenRouteService: `ROUTER=ors` и `ORS_API_KEY=...` в `.env`
(бесплатный ключ на https://account.heigit.org/signup).

## Если вы уже запускали прошлую версию (Центральный район)

1. В своем `.env` замените границы и название (или скопируйте `.env.example` заново):
   `VITE_PILOT_BOUNDS=83.05,54.82,83.14,54.875` и `VITE_PILOT_NAME=Академгородок, Новосибирск`.
   Строки `ORS_*` можно убрать — ключ больше не нужен.
2. `npm run seed -- --reset` — старые точки удалятся, появятся демо-точки Академгородка.
3. Перезапустите `npm run dev`.


## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | API + клиент в режиме разработки |
| `npm run build` / `npm start` | Собрать клиент и запустить все на одном порту |
| `npm run seed` | Добавить демо-точки, если база пустая |
| `npm run seed -- --reset` | Удалить все точки, сигналы и фото и заново добавить демо-набор |
| `npm run delete-point -- <id>` | Удалить точку вместе с фото |
| `npm test` | Unit и серверные тесты (35 тестов) |
| `npm run typecheck` | Проверка типов |

## Устройство

```
shared/     справочник категорий, параметры MVP, валидация, расстояние до линии — общие для клиента и сервера
server/     API на Express + SQLite + папка фото
src/        React-клиент: карта MapLibre, панели, форма, PWA
tests/      vitest
```

### Отличие от ТЗ: локальный сервер вместо Supabase

В ТЗ бэкенд — облачный Supabase. Для запуска на локалке без аккаунтов и Docker его роль
выполняет небольшой сервер `server/`, который повторяет те же контракты и правила:

| В ТЗ (Supabase) | Здесь |
|---|---|
| Anonymous sign-in, JWT | `POST /api/auth/anonymous` → токен в localStorage |
| Таблицы `obstacles`, `reports` с CHECK и UNIQUE | Те же таблицы и ограничения в SQLite (`server/db.ts`) |
| RLS: публичное чтение без `created_by` | `GET /api/obstacles` отдает только публичные поля; фото — по ID точки, без ID автора |
| RLS: вставка только со своим `created_by` | Сервер берет `created_by` из сессии, фото принимает только из своей папки |
| Storage bucket + policy | `PUT/DELETE /api/storage/photos/<сессия>/<точка>.webp`, проверка сигнатуры файла, лимит 5 МБ |
| RPC `report_obstacle` (SECURITY DEFINER) | `POST /api/rpc/report_obstacle`, одна транзакция, пороги 1 → disputed, 3 → hidden |
| Edge Function `route-wheelchair` → OpenRouteService | `POST /api/functions/route-wheelchair`: проверка сессии, границ, 20 запросов в час, таймаут 6 с; движок — Valhalla (OSM) или ORS, см. `server/routing.ts` |

Клиент ходит в API только через `src/api/client.ts`, поэтому при переезде на Supabase
меняется этот файл, а схема из `server/db.ts` переносится в SQL-миграцию почти без правок.

### Что реализовано по ТЗ

FR 01–12: пилотный район и геолокация, кластеры, фильтры и пресет «Для коляски», карточка,
маршрут wheelchair с предупреждениями в пределах 30 м (спорные точки — отдельным списком),
выбор координаты нажатием или центром карты, фото JPEG/PNG/WebP до 5 МБ со сжатием до 1600 px
и удалением EXIF, запись точки только после загрузки фото, анонимная сессия, один сигнал на сессию,
disputed/hidden по порогам. NFR: кнопки от 44×44, фокус виден, все действия доступны с клавиатуры
(координату можно выбрать кнопкой «центр карты», точки открываются из списка), черновик формы
живет до закрытия вкладки, ошибки маршрута не блокируют карту.

## Smoke-проверка (AT из ТЗ)

1. Открыть без разрешения геолокации — видно Академгородок и 9 точек (AT 01).
2. Отдалить карту — точки собираются в кластер с числом; нажатие раскрывает (AT 02).
3. «Для коляски» — остаются только зеленые значки (AT 03).
4. «Маршрут» → два нажатия на карту — линия, расстояние, предупреждения (AT 04).
   Для AT 05 поставьте в `.env` `VALHALLA_URL=http://localhost:1` — ошибка, отсчет 30 с, карта работает.
5. Открыть точку — фото, состояние, описание, время (AT 06).
6. «Добавить точку» → «Опубликовать» с пустой формой — поля подсвечены (AT 07).
7. Выбрать PDF или файл больше 5 МБ — отклонен сразу (AT 08).
8. Заполнить форму с фото — точка появилась на карте (AT 09).
9. Остановить API (`Ctrl+C`) и отправить форму — поля на месте, можно повторить (AT 10).
10. «Сообщить об изменении» — статус «спорная» (AT 11); повтор — «Вы уже сообщали» (AT 12).
    Для третьего сигнала откройте точку в двух других окнах инкогнито (AT 13).
11. Пройти сценарии клавишей Tab (AT 14).

## Известные ограничения

- Демо-точки выдуманы. Перед пилотом замените их проверенным набором.
- Тайлы `tile.openstreetmap.org` подходят для разработки; для пилота выберите провайдера
  тайлов и проверьте условия атрибуции (`VITE_TILE_URL`).
- Шрифт для чисел на кластерах грузится с demotiles.maplibre.org, шрифт интерфейса — с Google Fonts.
  Без интернета интерфейс переходит на системный шрифт.
- Сервер Valhalla от FOSSGIS — бесплатный демо-сервис без гарантий доступности (см. раздел про маршрут).
- Node печатает `ExperimentalWarning: SQLite is an experimental feature` — это нормально.
- Офлайн-режима нет (так задумано в MVP).
